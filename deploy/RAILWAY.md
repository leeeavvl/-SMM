# Деплой на Railway (без покупки своего сервера)

Railway — облачный хостинг, разворачивает приложение прямо из GitHub-репозитория.
У него нет бессрочного бесплатного тарифа (обычно пробный кредит, дальше — по
факту использования, недорого для такого маленького приложения), но не нужно
арендовать и администрировать VPS самим — деплой в несколько кликов.

⚠️ Локальная Ollama (бесплатный провайдер ИИ) на Railway работать не будет —
это ваш собственный компьютер, из облака до него не достучаться. На Railway
нужен провайдер с облачным API: проще всего Google Gemini (тоже есть
бесплатный уровень) — ключ настраивается прямо в приложении после деплоя.

## 1. Создать проект

1. Зайдите на **railway.app**, войдите через GitHub
2. **New Project → Deploy from GitHub repo** → выберите этот репозиторий
   (`leeeavvl/-SMM`)
3. Railway сам распознает Python-приложение (Nixpacks) и запустит сборку по
   `requirements.txt`. Команда запуска уже задана в `Procfile`
   (`uvicorn app.app:app --host 0.0.0.0 --port $PORT`) — ничего вручную
   прописывать не нужно.

## 2. Постоянное хранилище (Volume)

Без этого шага база данных и загруженные файлы будут исчезать при каждом
передеплое — обязательно сделайте это сразу.

1. В проекте на Railway: **Settings → Volumes → New Volume**
2. Mount path: `/app/data`
3. В **Settings → Variables** добавьте переменную:
   ```
   DATA_DIR=/app/data
   ```

Загруженные медиафайлы (`static/uploads`) при первом деплое без volume тоже
будут теряться при каждом обновлении кода — это менее критично (можно
перезалить), но при желании можно смонтировать второй Volume на
`/app/static/uploads`.

## 3. Пароль на вход (обязательно, у приложения нет своей авторизации)

В **Settings → Variables** добавьте:
```
APP_AUTH_USER=ваш_логин
APP_AUTH_PASSWORD=ваш_пароль
```
Без этих двух переменных приложение отвечает как обычно — авторизация
включается только если обе заданы. С ними — Railway при заходе на сайт
попросит логин/пароль (Basic Auth) у каждого посетителя.

## 4. Домен

- Бесплатный вариант: Railway сам выдаёт поддомен вида
  `ваш-проект.up.railway.app` — работает сразу после деплоя
- Свой домен (`legalcareerist.ru`): **Settings → Networking → Custom Domain**
  → укажите домен → Railway покажет CNAME-запись → добавьте её у
  регистратора/в DNS домена

## 5. Настроить ИИ-провайдера

После деплоя откройте сайт → **Настройки → Источник ИИ-генерации** → выберите
**Google Gemini** → вставьте бесплатный ключ с ai.google.dev (см. более
раннюю инструкцию). Ollama на Railway недоступна.

## 6. Обновить Canva Redirect URI

Если используете интеграцию с Canva — добавьте в неё ещё один Redirect URI
под адрес на Railway/ваш домен:
```
https://ваш-домен-или-поддомен/api/canva/oauth/callback
```

## Обновление после изменений в коде

Railway передеплоивает автоматически при каждом `git push` в подключённую
ветку — ничего вручную делать не нужно.
